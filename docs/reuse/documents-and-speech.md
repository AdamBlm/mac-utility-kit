# Open-source reuse for Docs and Text & Speech

The map covers 23 document tools and 9 text and speech tools. **Direct** covers the core operation. **Partial** covers a working implementation with a named parity gap. **Building block** identifies a component that needs application-specific logic. The mapping is based on repository source, upstream documentation, and license notices. Integration and output quality were assessed from those sources.

## Docs (23)

| Feature | Repository and license | Fit and integration |
| --- | --- | --- |
| Scan Document | [Offscan](https://github.com/bartoszpiech/offscan/tree/main/FlatlyCore) (MIT) | **Partial.** Reuse the macOS-compatible Swift core for imported photo detection, deskew, cleanup, and PDF assembly. Use system Continuity Camera for document capture from a Mac. Offscan's camera UI targets iPhone and iPad. |
| Redact PDF | [Nib](https://github.com/daniel-alexander4/nib) (AGPL-3.0), [MuPDF](https://github.com/ArtifexSoftware/mupdf) (AGPL-3.0 or commercial) | **Direct.** Nib documents permanent redaction. Reuse or study its workflow, or use MuPDF's [apply-redactions operation](https://pymupdf.readthedocs.io/en/latest/page.html#Page.apply_redactions) with an original selection UI. Verify removed text and embedded image data on representative files. |
| Fill & Flatten Forms | [Nib](https://github.com/daniel-alexander4/nib) (AGPL-3.0), [AcroForge](https://github.com/san64777/acroforge) (Apache-2.0), [pypdf](https://github.com/py-pdf/pypdf) (BSD-3-Clause) | **Direct** with Nib for detected fields on scans and flat forms, editable AcroForms, filling, and flattening. The permissive path is **partial**. AcroForge detects on vector pages and inserts widgets at given coordinates on scans. Add scan detection separately and use pypdf's [form operations](https://pypdf.readthedocs.io/en/stable/user/forms.html) for filling and flattening. |
| Make PDF Searchable | [OCRmyPDF](https://github.com/ocrmypdf/OCRmyPDF) (MPL-2.0) | **Direct.** Use the local CLI to add an OCR text layer to scans. Confirm the chosen OCR/rasterization dependencies for the macOS package. |
| PDF to Word | [pdf2docx](https://github.com/ArtifexSoftware/pdf2docx) (MIT, depends on AGPL-3.0 or commercially licensed PyMuPDF) | **Partial.** Produces editable DOCX and reconstructs page layout from text-based PDFs. Validate native heading/list semantics and add OCR for image-only PDFs. |
| Sign PDF | [Nib](https://github.com/daniel-alexander4/nib) (AGPL-3.0), [pdf-lib](https://github.com/Hopding/pdf-lib) (MIT) | **Partial.** Nib supplies a drawn-signature workflow. For a permissive implementation, use pdf-lib to place text or a rendered signature image and add original type, drawing, and placement controls. |
| Merge PDFs | [OpenShelf PDFTools.swift](https://github.com/Manan-Santoki/OpenShelf/blob/main/Sources/OpenShelf/Tools/PDF/PDFTools.swift) (MIT) | **Direct.** Swift/PDFKit implementation combines PDFs and images in user-specified order. |
| Split PDF | [OpenShelf PDFTools.swift](https://github.com/Manan-Santoki/OpenShelf/blob/main/Sources/OpenShelf/Tools/PDF/PDFTools.swift) (MIT) | **Direct.** Reuse its page-range parsing and split implementation. |
| Organize PDF | [OpenShelf PDFPagesEditor.swift](https://github.com/Manan-Santoki/OpenShelf/blob/main/Sources/OpenShelf/Tools/PDF/PDFPagesEditor.swift) (MIT) | **Direct.** Use the page reorder, rotation, and removal logic in an original editor. |
| Delete Pages | [qpdf](https://github.com/qpdf/qpdf) (Apache-2.0) | **Direct.** Write a new file from the complement of the selected page ranges. Validate bookmarks and forms in edited copies. |
| Extract Pages | [qpdf](https://github.com/qpdf/qpdf) (Apache-2.0) | **Direct.** Provide selected page ranges to qpdf's page-selection CLI or library. |
| Images to PDF | [OpenShelf PDFTools.swift](https://github.com/Manan-Santoki/OpenShelf/blob/main/Sources/OpenShelf/Tools/PDF/PDFTools.swift) (MIT) | **Direct.** Its combine operation accepts image-only inputs and preserves their chosen order. |
| Crop PDF | [pypdf](https://github.com/py-pdf/pypdf) (BSD-3-Clause) | **Direct.** Set page crop boxes from selection coordinates. Cropping changes visible bounds and can leave out-of-bounds content in the file. |
| Compress PDF | [OpenShelf PDFTools.swift](https://github.com/Manan-Santoki/OpenShelf/blob/main/Sources/OpenShelf/Tools/PDF/PDFTools.swift) (MIT) | **Partial.** Reuse JPEG quality and resolution controls. Check preservation of selectable text, forms, and links before adopting any path that rasterizes whole pages. [pypdf](https://github.com/py-pdf/pypdf) (BSD-3-Clause) also documents targeted embedded-image replacement and recompression. |
| Add Password | [qpdf](https://github.com/qpdf/qpdf) (Apache-2.0) | **Direct.** Encrypt with user and owner passwords and set print/extraction restrictions. PDF viewers enforce the restrictions. |
| Remove Password | [qpdf](https://github.com/qpdf/qpdf) (Apache-2.0) | **Direct.** Decrypt to a new file after supplying the document password. |
| PDF to Images | [PDFium](https://github.com/chromium/pdfium) (BSD-3-Clause core, third-party notices) | **Building block.** Rasterize PDF pages and use macOS Image I/O or an external encoder for PNG, JPEG, or HEIC. |
| Convert Documents | [Pandoc](https://github.com/jgm/pandoc) (GPL-2.0-or-later), [LibreOffice](https://github.com/LibreOffice/core) ([MPL-2.0 with third-party licenses](https://www.libreoffice.org/licenses/)) | **Direct with routing.** Pandoc handles Markdown, HTML, DOCX, ODT and text workflows. Route unsupported combinations, including RTF input, through LibreOffice. Publish the supported input/output matrix and test round trips. |
| Word to PDF | [LibreOffice](https://github.com/LibreOffice/core) ([MPL-2.0 with third-party licenses](https://www.libreoffice.org/licenses/)) | **Direct.** Invoke Writer's headless PDF export for DOC/DOCX, RTF and text. |
| PowerPoint to PDF | [LibreOffice](https://github.com/LibreOffice/core) ([MPL-2.0 with third-party licenses](https://www.libreoffice.org/licenses/)) | **Direct.** Invoke Impress's headless PDF export and validate fonts and slide masters. |
| Excel to PDF | [LibreOffice](https://github.com/LibreOffice/core) ([MPL-2.0 with third-party licenses](https://www.libreoffice.org/licenses/)) | **Direct.** Invoke Calc's headless PDF export and respect sheet print areas and scaling. |
| Web Page to PDF | [Playwright](https://github.com/microsoft/playwright) (Apache-2.0, browser components have separate notices) | **Partial.** Chromium's [page.pdf API](https://playwright.dev/docs/api/class-page#page-pdf) provides paginated printing. Continuous-page export needs sizing and testing against very long pages. |
| Markdown to PDF | [Pandoc](https://github.com/jgm/pandoc) (GPL-2.0-or-later), [WeasyPrint](https://github.com/Kozea/WeasyPrint) (BSD-3-Clause) | **Direct.** Convert Markdown using Pandoc, either through a supported PDF engine or via HTML rendered by WeasyPrint. |

## Text & Speech (9)

| Feature | Repository and license | Fit and integration |
| --- | --- | --- |
| Transcribe | [whisper.cpp](https://github.com/ggml-org/whisper.cpp) (MIT) | **Direct with media decoding.** Use the local Whisper engine and its timestamped output. Decode video soundtracks and audio formats to supported audio using the media pipeline. |
| Summarize | [MLX Swift LM](https://github.com/ml-explore/mlx-swift-lm) (MIT) | **Building block.** Swift-native local language-model inference on Apple silicon. Add text extraction, summary prompts, and long-document chunking. |
| Extract Text | [doc-indexer-macos](https://github.com/Bouliw/doc-indexer-macos) (MIT) | **Direct.** Its Swift OCR utility processes images and PDF pages locally with Vision. Add the editor and clipboard affordances in the app. |
| Capture Text | [TextGrab](https://github.com/arsh342/TextGrab) (MIT) | **Direct.** Reuse or adapt its region selection, ScreenCaptureKit capture, local Vision recognition, and pasteboard flow. |
| Translate | [Argos Translate](https://github.com/argosopentech/argos-translate) (MIT), [Argos Translate Files](https://github.com/LibreTranslate/argos-translate-files) (AGPL-3.0) | **Partial.** Use the offline translation engine. The files project targets text, Office and SRT among other formats. Confirm formatting and subtitle timing per format, or retain the structure in app-owned parsers while translating only text segments. |
| Text to Speech | [Sotto](https://github.com/Shreysid/Sotto) (Apache-2.0), [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) (Apache-2.0) | **Partial.** Sotto demonstrates local macOS text playback with Kokoro. sherpa-onnx supplies a local TTS output pipeline. Reuse document extraction and implement preview plus audio-file export. Check voice model terms separately. |
| Ask a Document | [MLXEdgeLLM](https://github.com/wangxuncaiGH/MLXEdgeLLM) (MIT), [Folio](https://github.com/taiwong2/Folio) (MIT) | **Partial.** MLXEdgeLLM has local retrieval and per-page PDF extraction. | Word Counter | [retext](https://github.com/retextjs/retext) (MIT), [reading-time](https://github.com/ngryman/reading-time) (MIT) | **Building block.** Use or adapt text tokenization and reading-speed estimates. Compute word frequencies and Unicode-aware character, sentence, and paragraph counts in the application. |
| Case Converter | [change-case](https://github.com/blakeembrey/change-case) (MIT) | **Direct for identifier styles.** Reuse its case rules or port them to Swift with attribution. Use locale-aware upper/lower transformations and define title-case rules for prose. |
