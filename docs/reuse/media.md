# Video, audio, and image reuse map

The 33 rows follow the [feature inventory](../feature-inventory.md). **Direct** means a source app implements the core workflow. **Building block** means a library or command can perform the operation and needs app integration. **Partial** means a capability still needs separate engineering. License notes refer to the upstream sources, and the mappings were reviewed from code and documentation without runtime tests.

| --- | --- | --- |

| Extract Frames | [FFmpeg](https://github.com/FFmpeg/FFmpeg) (LGPL/GPL, build-dependent), [OpenShelf](https://github.com/Manan-Santoki/OpenShelf/blob/main/Sources/OpenShelf/Convert/ImageConversion.swift) (MIT) | **Building blocks.** Decode the selected frames to PNG/JPEG, with the Swift image conversion code as a reference for HEIC export. | Record Screen | [Open Recorder](https://github.com/imbhargav5/open-recorder) (Apache-2.0), [AutoZoomRecorder](https://github.com/linsipeng/AutoZoomRecorder) (MIT) | **Direct references.** Open Recorder captures a display, window, or region with mic/system audio and pointer events. | Compress Video | [OpenShelf](https://github.com/Manan-Santoki/OpenShelf/blob/main/Sources/OpenShelf/Tools/Media/VideoCompressEditor.swift) (MIT), [FFmpeg](https://github.com/FFmpeg/FFmpeg) (LGPL/GPL, build-dependent) | **Direct reference.** Adapt OpenShelf's compression workflow and select encoder quality, hardware support, fallback, and output reporting. |
| Convert Video | [OpenShelf](https://github.com/Manan-Santoki/OpenShelf/blob/main/Sources/OpenShelf/Convert/MediaConversion.swift) (MIT), [FFmpeg](https://github.com/FFmpeg/FFmpeg) (LGPL/GPL, build-dependent) | **Direct reference.** Adapt native and FFmpeg conversion paths. | Resize Video | [FFmpeg](https://github.com/FFmpeg/FFmpeg) (LGPL/GPL, build-dependent) | **Building block.** Use the [scale filter](https://ffmpeg.org/ffmpeg-filters.html#scale) with explicit dimensions, aspect policy, and encoder-compatible sizes. |
| Crop & Rotate Video | [OpenShelf](https://github.com/Manan-Santoki/OpenShelf/blob/main/Sources/OpenShelf/Tools/Media/VideoCropEditor.swift) (MIT), [FFmpeg](https://github.com/FFmpeg/FFmpeg) (LGPL/GPL, build-dependent) | **Direct reference.** Adapt the crop editor and use [crop, transpose, and flip filters](https://ffmpeg.org/ffmpeg-filters.html) for transformations. Account for source orientation metadata. |
| Media Info | [FFmpeg](https://github.com/FFmpeg/FFmpeg) (LGPL/GPL, build-dependent), [MediaInfoLib](https://github.com/MediaArea/MediaInfoLib) (BSD-2-Clause) | **Building blocks.** Read JSON from [ffprobe](https://ffmpeg.org/ffprobe.html) or integrate MediaInfoLib. | Trim Video | [LosslessCut](https://github.com/mifi/lossless-cut) (GPL-2.0), [FFmpeg](https://github.com/FFmpeg/FFmpeg) (LGPL/GPL, build-dependent) | **Direct reference.** Use LosslessCut to study the keyframe-aware UX and drive FFmpeg stream copy. Lossless cuts can be limited by keyframe placement. |
| Merge Videos | [OpenShelf](https://github.com/Manan-Santoki/OpenShelf/blob/main/Sources/OpenShelf/Tools/Media/MediaMergeEditor.swift) (MIT), [FFmpeg](https://github.com/FFmpeg/FFmpeg) (LGPL/GPL, build-dependent) | **Direct reference.** Reuse the ordering workflow. [Concatenate matching streams](https://ffmpeg.org/ffmpeg-formats.html#concat) and normalize incompatible inputs before joining. |
| Mute Video | [OpenShelf](https://github.com/Manan-Santoki/OpenShelf/blob/main/Sources/OpenShelf/Tools/Media/MediaTools.swift) (MIT), [FFmpeg](https://github.com/FFmpeg/FFmpeg) (LGPL/GPL, build-dependent) | **Direct reference.** Copy the video stream and exclude audio tracks through [stream selection](https://ffmpeg.org/ffmpeg.html#Stream-selection). Preserve compatible metadata and captions if requested. |
| Replace Audio | [FFmpeg](https://github.com/FFmpeg/FFmpeg) (LGPL/GPL, build-dependent) | **Building block.** Stream-map a replacement or mix it through the [amix filter](https://ffmpeg.org/ffmpeg-filters.html#amix). Set durations, looping, gains, and track selection in the app. |
| Video to GIF | [Gifski for macOS](https://github.com/sindresorhus/Gifski) (MIT application wrapper) | **Direct reference.** Adapt clip selection, frame rate, sizing, and progress. Verify licenses for the actual encoder and other dependencies before redistribution. |
