# Upstream reuse in the current app

| Area | Reuse decision | Remaining app responsibility |
| --- | --- | --- |
| Resize Images | The native path delegates decoding, EXIF orientation, raster drawing, and file writing to Image I/O and Core Graphics. The optional ImageMagick 7 path delegates resizing, center-crop, and encoding directly to ImageMagick. | Share the sizing rules and preview between both engines. Validate the output dimensions before publishing. Keep input and output staging in the app. |
| Merge PDFs | PDFKit loads, unlocks, renders, and merges pages in one workflow that also accepts images. qpdf remains a candidate for PDF-only document structure operations. Introducing it for this workflow would still require an image-to-PDF path and PDFKit thumbnails, plus a new executable and parity tests for locked and mixed inputs. | The app owns selection syntax, source order, names, and preview. Whole-document structure such as outlines and tags needs dedicated evaluation before making preservation claims. |
| Compress Video | FFmpeg directly encodes with x264 and x265 when the user selects it. The native AVFoundation path gives a no-setup option with source-size encoding. HandBrake informs the separate sizing and quality controls. | Select codec and quality, orchestrate local batches and previews, and validate output resolution before publishing. |
| Convert Video | AVFoundation export sessions transcode or pass through supported Apple containers. FFmpeg extends format and filter support, including WebM. | Validate settings, report observed codecs and unsupported streams, and publish staged outputs. [AVFoundation export](https://developer.apple.com/documentation/avfoundation/exporting-video-to-alternative-formats) · [FFmpeg stream copy](https://ffmpeg.org/ffmpeg.html#Streamcopy) |
| Change Speed | AVFoundation scales the edit timeline, exports video and audio, and uses native pitch algorithms. FFmpeg directly applies the timing and sample-rate filters when pitch follows speed. | Preserve track orientation and audio offsets, keep preview and export aligned, and validate playable output. [AVFoundation composition](https://developer.apple.com/documentation/avfoundation/avmutablecomposition/scaletimerange(_:toduration:)) · [FFmpeg filters](https://ffmpeg.org/ffmpeg-filters.html) |
| Extract Frames | AVFoundation seeks and decodes frames with the track transform. Apple Image I/O writes the selected still image format. FFmpeg’s frame extraction workflows inform time and interval selection. | Validate timestamps and cap the frame count, publish per-source results, and report skipped frames. [AVAssetImageGenerator](https://developer.apple.com/documentation/avfoundation/avassetimagegenerator) · [FFmpeg documentation](https://ffmpeg.org/ffmpeg.html) |
| Trim Video | AVFoundation exports an explicit time range for precise MP4. LosslessCut informs the keyframe-aligned selection. FFmpeg copies streams and ffprobe locates keyframes and inspects the MKV result. | Preview the projected bounds and verify the exported duration, streams, and first pictured frame. [LosslessCut](https://github.com/mifi/lossless-cut/blob/master/docs/features.md) · [AVFoundation export range](https://developer.apple.com/documentation/avfoundation/avassetexportsession/timerange) |
| Mute Video | Native AVFoundation composition and passthrough export preserve compressed video through supported containers. [AVFoundation passthrough](https://developer.apple.com/documentation/avfoundation/avassetexportpresetpassthrough) · [FFmpeg stream copy](https://ffmpeg.org/ffmpeg.html#Stream-copy) |

| Video to GIF | FFmpeg generates and applies an optimized palette during animated GIF export. Image I/O verifies the output and supplies animation metadata. [FFmpeg palette filters](https://ffmpeg.org/ffmpeg-filters.html#palettegen) · [Gifski](https://github.com/sindresorhus/Gifski) |
| Crop & Rotate Video | Reuses the native AVFoundation geometry renderer. [FFmpeg video filters](https://ffmpeg.org/ffmpeg-filters.html#crop) |
| Merge Videos | AVFoundation builds and exports the combined timeline. References include [ImageMagick resize and crop geometry](https://usage.imagemagick.org/resize/), [PDFKit](https://developer.apple.com/documentation/pdfkit), [qpdf page selection](https://qpdf.readthedocs.io/en/stable/cli.html#page-selection), [FFmpeg codec options](https://ffmpeg.org/ffmpeg-codecs.html), and [HandBrake quality settings](https://handbrake.fr/docs/en/latest/technical/video-cq-vs-abr.html).

To run the engine integration fixtures, set `MAC_UTILITY_MAGICK_TEST` to the installed `magick` binary and `MAC_UTILITY_FFMPEG_TEST` to an FFmpeg binary that includes libx264, libx265, and the libass subtitles filter, then run `swift test`. The fixtures verify actual output sizes, PDF page order, video resolution and orientation, original-file preservation, and staging cleanup.
