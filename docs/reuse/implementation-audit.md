# Upstream reuse in the current app

| Area | Reuse decision | Remaining app responsibility |
| --- | --- | --- |
| Resize Images | The native path delegates decoding, EXIF orientation, raster drawing, and file writing to Image I/O and Core Graphics. The optional ImageMagick 7 path delegates resizing, center-crop, and encoding directly to ImageMagick. | Share the sizing rules and preview between both engines. Validate the output dimensions before publishing. Keep input and output staging in the app. |
| Merge PDFs | PDFKit loads, unlocks, renders, and merges pages in one workflow that also accepts images. qpdf remains a candidate for PDF-only document structure operations. Introducing it for this workflow would still require an image-to-PDF path and PDFKit thumbnails, plus a new executable and parity tests for locked and mixed inputs. | The app owns selection syntax, source order, names, and preview. Whole-document structure such as outlines and tags needs dedicated evaluation before making preservation claims. |
| Compress Video | FFmpeg directly encodes with x264 and x265 when the user selects it. The native AVFoundation path gives a no-setup option with source-size encoding. HandBrake informs the separate sizing and quality controls. | Select codec and quality, orchestrate local batches and previews, and validate output resolution before publishing. |
| Convert Video | AVFoundation export sessions transcode or pass through supported Apple containers. FFmpeg extends format and filter support, including WebM. | Validate settings, report observed codecs and unsupported streams, and publish staged outputs. [AVFoundation export](https://developer.apple.com/documentation/avfoundation/exporting-video-to-alternative-formats) · [FFmpeg stream copy](https://ffmpeg.org/ffmpeg.html#Streamcopy) |
| Media Info | AVFoundation supplies native stream properties and bounded presentation-timing observations. A selected ffprobe supplies container and stream JSON as a separate engine. | Group stream information, label estimates, show source filenames, and export each engine’s JSON. [ffprobe](https://ffmpeg.org/ffprobe.html) |
| Extract Audio | AVFoundation selects and exports native tracks. FFmpeg supplies MP3 and FLAC encoding. | Present language and track index, preview the selected track, and validate container compatibility. [FFmpeg stream selection](https://ffmpeg.org/ffmpeg.html#Stream-selection) |
| Convert Images | Apple Image I/O encodes supported native formats. ImageMagick adds WebP with an explicit local executable. | Verify orientation, dimensions, alpha, and profile handling. Export the primary image with the requested metadata and matte options. [Image I/O](https://developer.apple.com/library/archive/documentation/GraphicsImaging/Conceptual/ImageIOGuide/ikpg_dest/ikpg_dest.html) · [ImageMagick options](https://imagemagick.org/command-line-options/) |
| Compress Images | Uses the conversion operation and its Image I/O and ImageMagick encoders. | Limit size-target attempts, report the measured result, and compare the before and after images. Multi-image inputs are rejected to preserve the source structure. |
| Remove Metadata | Image I/O supplies native lossless metadata copying for supported location removal. ExifTool supplies the advanced group operations. | Inspect before and after, reject failed or unverifiable scrubs, and verify display-critical image properties. Initial scope is single-image JPEG and PNG. [Image I/O metadata copy](https://developer.apple.com/library/archive/qa/qa1895/_index.html) · [ExifTool FAQ](https://exiftool.org/faq.html) |
| Split PDF, Organize PDF, Delete Pages | PDFKit opens and copies pages directly and provides the thumbnails. The behavior was compared with qpdf page selection and rotation. PDFKit enables the no-setup workflow, and qpdf also documents limitations for document-level data in page operations. | Own the selection plan, undo and redo, output grouping and names, and staged publication. Verify page order, rotation, content, and input preservation. [PDFKit](https://developer.apple.com/documentation/pdfkit) · [qpdf page selection](https://qpdf.readthedocs.io/en/stable/cli.html#page-selection) |
| Extract Pages | Reuses PDFKit page copying and the shared selection parser. qpdf page selection was used as a workflow reference. | Apply document or explicit selection order and stage the verified PDF. [qpdf page selection](https://qpdf.readthedocs.io/en/stable/cli.html#page-selection) |
| Images to PDF, PDF to Images | Uses Image I/O for orientation-aware image decoding and export, Core Graphics for PDF page composition, and PDFKit for drawing PDF pages with visible annotations. ImageMagick density and MuPDF rasterization informed the sizing and format controls. | Coordinate paper layout, bounded raster sizes, previews, and multi-output publication. [Apple Quartz PDF guide](https://developer.apple.com/library/archive/documentation/GraphicsImaging/Conceptual/drawingwithquartz2d/dq_pdf/dq_pdf.html) · [ImageMagick density](https://imagemagick.org/command-line-options/#density) · [MuPDF tools](https://github.com/ArtifexSoftware/mupdf/blob/master/docs/man/mutool.1) |
| Sign PDF | PDFKit supplies PDF permissions, visible ink annotations, and PDF writing; Core Text supplies typed glyph shapes. pypdf overlay workflows were reviewed as a reference. | Own the signature canvas, visual placement in displayed coordinates, and read-back verification. [PDFKit ink annotations](https://developer.apple.com/documentation/pdfkit/pdfannotation/add(_:)) · [pypdf overlay reference](https://pypdf.readthedocs.io/en/stable/user/add-watermark.html) |
| Extract Text | Apple Vision performs native local OCR; PDFKit supplies embedded text and the existing PDF raster path handles scanned pages. | Apply page and region selection, report per-page failures, and export plain text. [Vision text recognition](https://developer.apple.com/documentation/vision/recognizing-text-in-images) |
| Word Counter | Apple Natural Language supplies native tokenization for words, sentences, and paragraphs. Existing reading-time libraries informed the transparent reading-speed calculation. | Count Unicode graphemes, rank case-folded words, and separate the draft and live UI from the counting operation. [NLTokenizer](https://developer.apple.com/documentation/naturallanguage/nltokenizer) · [reading-time](https://github.com/ngryman/reading-time) |
| QR Code | Core Image generates QR modules, Vision detects barcodes, and Image I/O writes PNG. ZXing documents Wi-Fi payload formatting. | Validate payloads, add an integer-scaled quiet zone, render custom colors, and present the detected payloads. [ZXing barcode contents](https://github.com/zxing/zxing/wiki/Barcode-Contents) |
| Batch Rename | Foundation provides file URLs, metadata, and directory listings. Darwin exclusive renames keep destinations from being overwritten during apply and undo. F2 informs dry-run previews, conflict checks, and undo. | Preview ordered naming rules, detect conflicts, and stage moves to support swaps and recovery. [F2](https://github.com/ayoisaiah/f2) |
| Keep Awake | IOKit owns process-scoped idle sleep assertions. KeepingYouAwake informs timed and indefinite session behavior. | Coordinate the active session and expiry across windows. [KeepingYouAwake](https://github.com/newmarcel/KeepingYouAwake) |
| JSON Formatter | Foundation decodes and validates JSON strings. DevToys informs the interface. A bounded token parser follows RFC 8259 so duplicate members and original numeric spellings are preserved through formatting. | Report duplicate keys, apply formatting options, and support loading and exporting UTF-8. [DevToys](https://github.com/DevToys-app/DevToys.Tools) · [RFC 8259](https://www.rfc-editor.org/rfc/rfc8259) |
| Base64 | Foundation provides Base64 conversion. RFC 4648 guides validation and the URL-safe alphabet. DevToys informs the text and file workflow. | Handle alphabet selection, hexadecimal and binary representations, previews, and decoded file export. The result is currently held in memory. [DevToys](https://github.com/DevToys-app/DevToys.Tools) · [RFC 4648](https://www.rfc-editor.org/rfc/rfc4648) |
| Hash Generator | CryptoKit provides the deployed hashing algorithms, with Swift Crypto as the open-source API reference. | Stream file data, validate and compare check values, and export reports. [Swift Crypto](https://github.com/apple/swift-crypto) |
| UI and jobs | SwiftUI, AppKit, and Foundation supply navigation, file pickers, Finder integration, process launch, and file operations. | Keep per-tool UI, job state, staging, and result reporting in the app. These behaviors connect the engines and user workflows. |
| Build and tests | SwiftPM builds and runs Swift Testing fixtures. GitHub Actions and Apple tooling build and verify the local app bundle. | Maintain representative output fixtures and CI wiring. No third-party engine is bundled. |

References include [ImageMagick resize and crop geometry](https://usage.imagemagick.org/resize/), [PDFKit](https://developer.apple.com/documentation/pdfkit), [qpdf page selection](https://qpdf.readthedocs.io/en/stable/cli.html#page-selection), [FFmpeg codec options](https://ffmpeg.org/ffmpeg-codecs.html), and [HandBrake quality settings](https://handbrake.fr/docs/en/latest/technical/video-cq-vs-abr.html).

To run the engine integration fixtures, set `MAC_UTILITY_MAGICK_TEST` to the installed `magick` binary and `MAC_UTILITY_FFMPEG_TEST` to an FFmpeg binary that includes libx264 and libx265, then run `swift test`. The fixtures verify actual output sizes, PDF page order, video resolution and orientation, original-file preservation, and staging cleanup.
