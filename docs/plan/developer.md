# Developer tools (14)

| Tool | Planned controls and outputs | Acceptance checks |
| --- | --- | --- |
| JSON Formatter | Paste or open UTF-8 JSON. Validate, format with 2 or 4 spaces or tabs, or minify. Offer optional alphabetical key sorting, copy, and export. | Locate syntax errors by line and column. Preserve large-number text and identify duplicate keys without silently rewriting them. |
| Base64 | Select Encode or Decode and Base64, Base64 URL-safe, Hex, or Binary. Accept text or files. Offer padding, wrap width, and UTF-8 or file output. | Round-trip arbitrary bytes and Unicode. Flag invalid characters and show a binary result as a file when it cannot be displayed as UTF-8. |
| Hash Generator | Choose MD5, SHA-1, SHA-256, SHA-384, or SHA-512. Hash typed text or one or more files. Enter an expected digest and copy or export results. | Match published test vectors, stream large files, show per-file errors, and label MD5 and SHA-1 as legacy. |
| UUID Generator | Generate v4 or v7 IDs in batches with case and hyphen options. Inspect a pasted UUID for variant, version, and v7 timestamp. Copy or export. | Verify UUID version and variant bits. Display the extracted timestamp only for v7. |
| JWT Decoder | Paste a token, view formatted header and payload, and show issued-at, expiry, and validity window. Optionally verify HMAC with the selected supported algorithm and a supplied secret. | Reject malformed tokens and algorithm mismatches. Keep parsed claims visibly unverified until verification succeeds. Keep secrets out of history. |
| Timestamp Converter | Convert in either direction between Unix time and date/time. Explicit seconds, milliseconds, and microseconds controls, time-zone selector, and ISO 8601 copy action. | Preserve microseconds and negative timestamps. Surface ambiguous or nonexistent local times around daylight-saving changes. |
| Diff Checker | Accept two texts or files. Switch inline/side-by-side view, ignore whitespace or case, highlight changed words, and navigate changes. | Handle empty input and files with different line endings. Report an unreadable file promptly and keep navigation in changed blocks synchronized. |
| Regex Tester | Enter pattern and sample, toggle case, multiline and dot-all options, inspect matches and named or numbered groups, and preview replacements. Copy results. | Surface compile errors, handle zero-width matches, and keep the UI responsive if matching times out. Document regex flavor and replacement syntax in the UI. |
| Clean Links | Paste links singly or line-by-line. Preview removed tracking parameters and supported redirect destinations. Copy individual or cleaned results. | Preserve functional query parameters and fragments. Decode only recognized wrapper formats locally and flag malformed URLs. |
| Coordinate Picker | Click a map or search a place, move or clear markers, copy decimal or degrees/minutes/seconds values, measure between points, and look up a pasted list. | Validate latitude/longitude bounds, handle unmatched entries independently, and retain manual coordinate format conversion when map search is unavailable. |
| Unicode Inspector | Display grapheme and code-point views with names, categories, UTF-8 bytes, and invisible character markers. Highlight possible confusables and optionally preview NFC/NFD. | Cover emoji sequences, combining marks, bidirectional controls, and zero-width whitespace. Normalization is an explicit action. |
| Lorem Ipsum | Choose word, sentence, or paragraph count. Generate plain text, HTML, or Markdown. Copy, regenerate, or save. | Check requested counts and output escaping. Cap elapsed work for excessive counts with a clear input limit. |
| Password Generator | Choose password or passphrase mode. Set length, allowed character groups or word count, separator, capitalization, and copy. Show strength feedback. | Use system cryptographic randomness, validate conflicting options, and exclude generated values from app history, logs, and automation. |
| CSV ↔ JSON | Choose CSV→JSON, JSON→CSV, or CSV→Markdown. Select delimiter and header handling, preview rows, and copy or export. Read CSV fields as strings by default. | Correctly round-trip quoted separators, newlines, empty cells, and Unicode. Flag unequal row lengths and unsupported nested JSON with row/field context. |
