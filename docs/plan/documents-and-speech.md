# Documents, text, and speech

Each row describes planned controls, output, and a release check. Page selection uses visible 1-based source page numbers. Where supported, the same thumbnail picker accepts click, Shift-click, and lists such as `1, 4–6`. Reflect changes in the preview before export and report invalid pages in place.

## Docs (23)

| Tool | Controls and workflow | Output and acceptance |
| --- | --- | --- |
| Scan Document | Capture through Continuity Camera where available or import photos. Edit the detected corner handles, rotate, choose original color, grayscale, or high contrast, reorder, and remove or retake individual pages. | Export a multipage PDF with the chosen paper size or original aspect ratio. Verify the result with a skewed image, a wrong corner detection, and camera cancellation. |
| Redact PDF | Mark text selections, search matches, or rectangular regions. Review and remove individual marks before applying. Choose black or white fill and preview all affected pages. | Export a sanitized copy. Verify selected text cannot be copied or extracted, marked image pixels are gone, and hidden data in affected annotations or metadata is handled. Check rotated pages and embedded images. |
| Fill & Flatten Forms | Fill existing supported fields or detect candidates on printed and scanned pages. Add or delete fields, choose text or checkbox, edit label and position, and add free text. Preview field placement. | Choose editable PDF or flattened copy. Verify field values survive reopening an editable export and render in the flattened export. Uncertain detected boxes require user review. |
| Make PDF Searchable | Choose OCR language or auto-detect, select pages, choose whether to skip pages with existing searchable text, and preview recognized text alongside the scan. | Export the PDF with a selectable text layer. Verify search and copy match a known fixture and page geometry stays aligned. Report pages that could not be recognized. |
| PDF to Word | Select pages, choose preserve-layout or flowing text, and enable OCR for scanned pages. Preview text and flag elements likely to lose fidelity. | Export DOCX with editable paragraphs, recognizable supported headings and lists, and supported images. Verify document opens in multiple readers and reports unsupported constructs or missing conversion engine. |
| Sign PDF | Type or draw a visible signature, then place, resize, or remove it on selected pages. Optionally add a dated text label. | Export a visibly signed copy and verify placement on rotated pages. Label this as a visual signature so users can distinguish it from certificate-based signing. |
| Merge PDFs | Queue PDFs and images, show expandable thumbnails for each source, and allow source reordering. Default to all pages per source. Show source labels, final page count, and the final order in preview. | Export one PDF under a chosen name. For A pages 1 and 4–6, B page 2, and one image, confirm six output pages in preview order. Reject malformed or out-of-bounds ranges and an empty final selection. Prompt for a locked source password and preserve other selections if unlock fails. |
| Split PDF | Split into one file per page, every N pages, or named custom ranges. Preview each group and configure a filename pattern with sequential numbering. | Export one PDF per group, with exact page counts and unique names. Validate ranges and explicitly show repeated pages where groups overlap. |
| Organize PDF | Reorder thumbnails, use keyboard alternatives to dragging, rotate selected pages in 90° increments, and remove or restore selected pages before export. Include undo and redo within the session. Add printable page numbers on selected output pages with a starting number, six positions, and a placement preview. | Export a new PDF matching the preview order and orientations. Block export with zero pages and verify number placement on rotated pages. |
| Delete Pages | Select pages by thumbnail or range. Toggle between viewing marked pages and the pages that will remain. Show the number of pages removed. | Export the remaining pages in original order. Block deletion of all pages and verify that the source and remaining page rotation are preserved. |
| Extract Pages | Choose individual pages or ranges; preview selection and choose document order or explicit selection order. | Export one PDF with the exact selected sequence. Validate duplicate selections consistently and reject an empty result. |
| Images to PDF | Import and reorder images. Choose original size or A4, Letter, or custom paper, margins, orientation, and fit or fill. Preview clipping for fill mode. | Export one page per image, including images rotated by EXIF and transparent images flattened onto the chosen page background. Validate page dimensions and order. |
| Crop PDF | Draw a crop box or enter edge offsets. Apply to one page, selected pages, or all pages. Preview against the page boundaries and expose a reset action. | Export a PDF with updated visible page boxes. Reject boxes outside the page or with zero area. Explain in the editor that cropping changes visibility and that Redact PDF removes content. |
| Compress PDF | Choose Smaller, Balanced, or Higher Quality, with optional image quality and DPI controls. Show an estimated result from a preview sample and handle PDFs without reducible images. | Export a copy and report original size, result size, and savings. Verify searchable text, links, and page order survive supported compression. If savings are absent, offer to keep the original. |
| Add Password | Set and confirm an open password. Optionally configure supported print and copy restrictions with an owner password and explain viewer enforcement. | Export encrypted PDF. Verify opening requires the correct password and selected restrictions are recorded. Keep credentials out of history and logs. |
| Remove Password | Unlock a selected PDF with its password, preview the document after unlocking, and choose an output name. | Export a decrypted copy only after successful unlock. A wrong password leaves source and destination untouched. |
| PDF to Images | Pick pages, select PNG, JPEG, or HEIC, choose DPI or pixel bounds, and adjust quality for lossy formats. Preview transparency and naming. | Write a numbered image per selected page and report unsupported encoders. Verify page order, output dimensions, and a mixed-size PDF at the selected resolution. |
| Convert Documents | Select a supported input and target pair among Word, OpenDocument, RTF, HTML, plain text, and Markdown. Preview where possible and offer batch conversion and filename controls. | Export converted copies and report unsupported pairs or unavailable engines before running. Verify representative formatting, links, Unicode, and intentional plain-text loss of styles. |
| Word to PDF | Queue supported Word, RTF, or text files. Choose all pages or a range after layout, paper size where supported, and review page breaks. | Export one PDF per source. Verify fonts, links, and pagination on a representative fixture. Identify missing dependencies and known layout substitutions. |
| PowerPoint to PDF | Pick all slides or a range, optionally include hidden slides, and choose individual slide pages or a handout layout where supported. Preview slide dimensions and order. | Export a PDF with the selected slide sequence. Report unsupported media and animations as static exports. Test a deck with hidden slides and missing fonts. |
| Excel to PDF | Choose sheets or a range, honor saved print areas or use the selection, and set paper, orientation, and fit-to-width where supported. Preview page breaks. | Export PDF using the selected print layout. Verify sheet order, repeated headers where supported, and no clipping for fit-to-width fixtures. |
| Web Page to PDF | Enter a URL, preview the loaded page, and select paginated or continuous output. Offer paper, margins, and optional print backgrounds for paginated mode. | Export rendered PDF. Handle failed navigation and overlong continuous pages with a specific message and a paginated option. Verify print styles and page order. |
| Markdown to PDF | Paste or open Markdown, preview rendered output, and choose typographic theme, paper, and margins. Resolve relative images only from the chosen source folder; identify broken resources. | Export a searchable PDF with headings, links, and code blocks. Verify UTF-8 text, page breaks, and long code lines. |

## Text & Speech (10)

| Tool | Controls and workflow | Output and acceptance |
| --- | --- | --- |
| Transcribe | Select audio or video, choose language or auto-detect, select a time range, and preview timestamped segments. Edit text before exporting. | Copy or export TXT, SRT, or VTT. Verify cue order and source-relative timecodes, including a trimmed selection and audio-free video. |
| Summarize | Paste text or open a supported document. Choose brief or detailed length, paragraph or bullet output, and scope where the document has pages. Show provider availability and progress. | Copy or export the summary. Validate that key fixture facts survive and identify unsupported or truncated material. Use the on-device Apple Intelligence model on eligible Macs. |
| Extract Text | Import images, screenshots, or PDFs. Select pages or crop to a region, choose recognition language, and review the text beside its source. | Copy or export editable plain text with optional page breaks. Verify reading order and page labels, show per-page failures, and handle scanned and text-native pages. |
| Capture Text | Select a screen region, adjust or retry the capture, and choose language. Preview detected text or enable immediate copy. | Copy text to the clipboard or open the result in Extract Text. Verify capture alignment across displays and show recovery guidance if screen recording permission is denied. |
| Translate | Choose source language or detection and target language. Accept plain text, supported documents, or SRT/VTT. Show side-by-side text and allow edits before export. | Copy translated text or export a supported document/subtitle copy. Verify subtitle timing, cue order, and supported document formatting remain intact. Identify unsupported language packs or structures. |
| Text to Speech | Paste text or open a supported document, select a voice, rate, and section, then preview playback with pause and seek. | Export audio in a supported format with its duration shown. Test unavailable or undownloaded voices and confirm the selected text range is spoken. |
| Ask a Document | Open a supported document, show indexing progress, and retain a session of follow-up questions. Each cited passage opens its page or section in the preview. | Provide locally generated answers with verifiable citations or indicate insufficient evidence. Check questions with known answers, rotated scanned pages, and questions outside the source. Use the on-device Apple Intelligence model on eligible Macs. Show model availability before indexing, and keep document indexing and preview available independently. |
| Word Counter | Paste text or load a plain-text file, show live word and character counts, optionally exclude spaces, configure reading speed, and show frequently used words. | Report words, characters, sentences, paragraphs, and estimated reading time. Test Unicode graphemes, empty text, repeated whitespace, and punctuation-only content. |
| Batch Find & Replace | Open or drop text files, choose literal or regular expression search, and preview replacements before exporting numbered copies with their original file extensions and Unicode encodings. | Export changed files only. Verify original files remain intact and reject a changed source until the batch is previewed again. |
| Case Converter | Paste text, select upper/lower/title/sentence or camelCase, snake_case, and kebab-case, and convert the whole input or selected lines. Preview changes with locale-aware text casing. | Copy or save the result. Test acronyms, punctuation, accented text, and existing identifier delimiters. |
