# Files and Mac tools

## Files (5)

| Tool | Planned subfeatures | Acceptance checks |
| --- | --- | --- |
| QR Code | Generate codes for plain text, URLs and Wi-Fi networks. Use fields for network name, security type and password. Choose error correction, size and foreground/background colors. Preview and copy or export PNG. Detect multiple QR codes or barcodes from a dropped image, display type and content, and copy selected results. | Standard readers can scan ASCII and Unicode text and Wi-Fi codes containing escaped punctuation. Low-contrast colors show a readability warning. Decoded URLs open only on deliberate action. Wi-Fi secrets stay out of history. |
| Batch Rename | Queue files with drag-and-drop or a picker. Stack replace, case conversion, numbering and date rules. Choose numbering start, increment and padding, date source, and whether to include extensions. Preview old and new names with per-file inclusion. Apply and offer undo from the completed run. | Validate invalid names and existing or intra-batch collisions before applying. Support case-only changes and swaps. Report partial failures and safely undo completed changes when original names remain available. |
| Find Duplicates | Scan selected folders with optional recursion and hidden-file inclusion. Group exact duplicates by content and display paths, sizes and dates. Preview and select copies to keep or move to Trash. Show estimated reclaimable space. | Keep at least one file in each group by default. Same-size files with different contents appear in separate groups. Recheck selected files at action time and report unreadable files or Trash failures individually. |
| Zip & Unzip | Create ZIPs from files and folders with a name, destination and optional password. List archive contents and allow full or selected extraction from ZIP, RAR, 7z and TAR. Prompt for passwords and offer skip or rename for existing destinations. | Cancel cleanly and show errors for encrypted, corrupt or unsupported entries. Reject paths and symlinks that could write outside the selected destination. Preserve original files and existing destination content. |
| Organize Downloads | Select a source folder and show downloaded images grouped by recorded web origin. Filter by origin and file type, preview an unknown-source group, and select images per group. Choose a folder export using copy or explicit move, or import selected groups into Photos albums. | Files without origin metadata stay in the unknown group. Avoid overwrite on duplicate names. Denied Photos access leaves the files in place and allows folder export. Show imported, skipped and failed items. |

## Mac (18)

| Tool | Planned subfeatures | Acceptance checks |
| --- | --- | --- |
| Network Speed Test | Start or cancel a test and display download, upload, responsiveness and test timestamp. Identify the active interface when available. Copy results as text and allow a fresh run. | Show missing or unsupported metrics as unavailable. Handle offline, timeout and interface-change cases with readable status. Cancel suppresses any later result from the canceled run. |
| Clipboard History | Enable recording explicitly. Capture supported text and image entries, search and filter, pin, copy back, remove individual entries and clear unpinned history. Provide a retention setting, pause mode and application exclusions. | Skip sensitive clipboard entries advertised as transient or concealed and entries attributable to excluded apps. Restore only the chosen item. Self-generated copies produce no duplicate. Pausing or disabling stops new entries. |
| Storage Explorer | Choose a folder or volume and drill down by file or folder size. Filter large files, show scan progress, reveal items in Finder and move explicitly selected items to Trash. Preview estimated size and unreadable locations. | Cancel a scan promptly. Avoid traversing symlink loops and counting hard links as separate reclaimable files. Recheck selected files before Trash and surface permission errors per item. |
| Wi-Fi Password & QR | Choose an available saved network or enter network details manually. Request system authorization for any supported credential lookup, mask the password by default, and offer a guest QR preview and explicit copy or export. | Denied authorization, unavailable passwords and unsupported network security types show clear status. Generated codes round-trip for supported security types. Credentials stay transient and are absent from logs and history. |
| Disk Speed Test | Select a mounted volume, test size and quick or repeated mode. Run sequential write/read measurements using a temporary test file, show throughput and progress, then allow result copying. | Check writability and free space before measuring. Remove the temporary file after completion, cancellation or error. Report volume removal and preserve other files. |
| Battery Health | Show charge, power source, charging state, cycle count, design and current capacity where available. Display battery condition and connected accessory charge levels when the device reports them. Provide refresh and report copying. | Desktop Macs show a clear no-internal-battery state. Missing fields show unavailable. Disconnected accessories stop appearing after refresh. |
| Keep Awake | Offer timed or indefinite sessions, a status display, stop action and optional display-awake setting. Provide common timer presets with a custom duration. | Starting and stopping updates status immediately. Expiry and app exit release the session. Explain when system policy prevents the requested behavior. |
| Uninstall App | Choose a removable application and review identifiable app-specific caches, preferences, support and data folders. Show sizes, paths and ownership rationale. Let users include or exclude each item before moving selected items to Trash. | System-managed apps and uncertain or shared items are excluded from removal. User data starts unselected. Confirm selection before Trash and report denied, changed or missing paths individually. |
| Presentation Mode | Independently choose desktop-item hiding, Dock hiding and keep-awake. Start for a fixed duration or until stopped. Show active status and restore settings upon exit from the session. | Ending or expiring a session restores captured values. Respect changes made by the user during the session and expose restoration errors. Recover from an interrupted session on next launch when safe. |
| Clean Keyboard | Temporarily suppress keyboard input with an on-screen countdown. Offer an optional dim overlay, a pointer-accessible stop action and automatic expiry. Explain required system permission before activation. | Permission denial leaves input working. Countdown expiry, stop and app exit restore normal input. The lock does not start on the system lock or login screen. |
| Dead Pixel Test | Choose a display and present full-screen black, white, red, green and blue backgrounds. Step manually or auto-cycle. Hide the cursor during inspection and support Escape to exit. | Validate that only the selected display changes. Auto-cycle pauses or ends on display disconnect. Exit restores normal windows and cursor. |
| Eject All Disks | List eligible external drives, cards and mounted images and group volumes by device. Choose an individual volume or eject all selected devices. Report each outcome and allow retry for busy volumes. | Omit startup/internal volumes from bulk action. Use standard eject and report busy volumes without force-ejecting. Handle disks already removed and mixed success. |
| Login & Background Items | List discoverable entries with publisher, source path and enabled state where available. Filter and reveal items. Route enable/disable changes through system-supported controls or System Settings when the entry cannot be directly managed. | Display unknown publisher or status explicitly. Reflect actual system state after changes or refresh. Missing files and manageability limits produce clear labels. |
| Fix “App Is Damaged” | Inspect a chosen app's identity, signing and available system assessment. Distinguish damaged, unverified and policy-blocked states where evidence permits. Offer a trusted-source redownload or the standard macOS approval flow where applicable. | Inspection leaves the app, its quarantine attributes and system protection settings intact. The tool neither approves nor launches apps automatically. Missing or invalid evidence shows an indeterminate diagnosis. |
| Reset Permissions | Choose an app and show eligible privacy categories. Preview the requested reset, confirm it, then show the result and explain when the app may ask again. Offer a System Settings handoff for unsupported categories. | Scope every available reset to the chosen app and category. Handle denial and unavailable reset methods without changing other apps. Report the actual system result. |
| Hidden Settings | Group reversible Finder, Dock and macOS preferences. Display current value and expected impact. Offer enable/disable or value controls, per-setting reset and a visible apply action. | Only supported preferences are editable. Apply and reset restore expected values. Explain any required Finder or Dock refresh before doing it. |
| Display Control | Select a detected external display and adjust available brightness, contrast or volume. Show per-display capability status, current value and supported ranges. Refresh on connect and disconnect. | Disable unsupported settings and avoid reporting a value as applied if the display does not accept it. Keep adjustments scoped to the selected display. |
| Mouse Fixes | Set scroll direction independently where mouse and trackpad can be identified. Add optional scroll-wheel acceleration or smoothing with a strength adjustment. Provide pause, restore defaults and permission status. | Verify both devices before enabling separate policies. Permission loss pauses interception and restores normal system input. Disconnects and unclassified devices do not inherit an unrelated policy. |
