# Open-source alternatives

The projects below cover different parts of the [Mac Utility Kit tool catalog](feature-inventory.md). The comparison uses their published documentation and declared licenses.

| Project | License | Documented overlap | Coverage gaps |
| --- | --- | --- | --- |
| [OpenShelf](https://github.com/Manan-Santoki/OpenShelf) | MIT | Native, offline drag-and-drop app with image editing and OCR, background removal, PDF page operations and compression, document conversion, and video and audio editing. | Its documented scope centers on files. It lacks documented coverage of Mac maintenance, the developer suite, document Q&A, and automatic PDF form detection. |
| [MacTools](https://github.com/mactools-app/MacTools) | GPL-3.0 | Native menu bar suite with scrolling screenshots, region recording, annotations, OCR, QR recognition, clipboard history, display controls, battery monitoring, input tweaks, and keep-awake. | Its documented scope centers on desktop and system utilities. It does not cover the broad media, Office/PDF conversion, and developer workflows. |
| [Toolzy](https://github.com/guilhermeeng99/Toolzy) | MIT | Desktop file toolbox for local PDF merge, compression and passwords, image conversion, audio and video conversion, yt-dlp downloads, and local Whisper transcription. | Mac system utilities and developer tools fall outside its documented scope. Its README describes building macOS locally. |
| [raycalrui/Toolbox](https://github.com/raycalrui/Toolbox) | MIT | Native macOS 15+ toolbox with video and subtitle workflows, clipboard history, password tools, and network utilities. | Considerably narrower PDF, image, and speech coverage. |
| [lazzyms/toolbox](https://github.com/lazzyms/toolbox) | MIT | Local desktop batch file utilities, including PDF password removal and image conversion, compression, and resizing. | Narrower file-focused scope. |
| [OmniTools](https://github.com/iib0011/omni-tools) | MIT | Self-hosted, browser-based image, video, PDF, text, and structured-data utilities. | Browser delivery leaves native Mac utilities such as display controls and login-item management outside its scope. |
| [DevToys](https://github.com/DevToys-app/DevToys) | MIT | Developer conversions, formatting, encoding, generation, and text inspection. | Specialist developer toolbox with limited overlap outside that category. |
| [BentoPDF](https://github.com/alam00000/bentopdf) | AGPL-3.0 | Browser-based PDF suite with page edits, OCR, forms, compression, and conversion. | PDF specialist. Form editing alone does not establish parity with automatic detection of fields on scanned forms. |
